# Project PAW – Sistem Pemesanan Kursus Online

Sistem ini dirancang untuk memfasilitasi proses belajar-mengajar secara daring. Sistem ini dibangun menggunakan **PHP Native**, **MySQL**, dan **HTML/CSS**, serta menyediakan fitur pemesanan, Aplikasi ini memisahkan secara jelas antarmuka untuk tiga jenis pengguna utama: Siswa (Student), Pengajar (Instructor), dan Administrator (Admin).

## Teknologi yang Digunakan
- **PHP Native**
- **MySQL**
- **HTML, CSS**
- **XAMPP / Laragon**
